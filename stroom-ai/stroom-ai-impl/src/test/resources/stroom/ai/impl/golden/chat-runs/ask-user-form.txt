# ask-user-form

ask_user shows its questions as a form (an ELICITATION card), and the run stops, holding nothing, until the user answers. The next run makes the call again, which gives the model the answers. A later call of the same step, never reached, is left out.

== What happened ==
The user asks: Find the failed logons.
Run 1: stopped to wait for the user (Questions in chat 7 need answers)
The user answers the form: ACCEPT, and the run carries on
Run 2: answered: Searching Production for the last 3 days.

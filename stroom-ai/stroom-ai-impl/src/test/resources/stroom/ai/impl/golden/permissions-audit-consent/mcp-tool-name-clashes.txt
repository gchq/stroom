- read_document_v2 -> MCP: Stroom/read_document_v2
- read -> MCP: Stroom/read
- stroom__stroom__read_document -> MCP: Stroom/stroom__read_document
- stroom__ls -> MCP: Stroom/ls
- find_docs -> MCP: Stroom/find_docs
- list_resources -> MCP: Stroom/list_resources
- other__find_docs -> MCP: other/find_docs
- other__read_document -> MCP: other/read_document
- other__stroom__read_document -> MCP: other/stroom__read_document
- stroom__find_docs -> MCP: stroom/find_docs
- stroom__read_document_4 -> MCP: stroom/read_document

* Feature **#5848** : Onboard feeds that aggregate several sources (a field such as a source type, Azure's Workload, or a log file path telling them apart): the survey finds the field, profiles each source type, and keeps a registry of them beside the feed. Each build translates one source type group, of the source types the user picks, in a pipeline of its own writing to the feed's Events or an output feed of its own; the rest are passed over, counted, and left for later builds. Groups writing to one feed share its index. A source type is matched by a field's value or by an anchored pattern on it, e.g. a directory of log files.

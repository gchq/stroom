* Feature **#6078** : A processor task that indexes a stream is now `Committing` once its run ends, until every index shard it wrote to has committed, and is then completed. A document that Lucene refuses, e.g. for a term that is too long, now fails its task, which is tried again and aborted on the third fault, instead of up to ten new shards being created for each document. Only a document refused as the type of one of its fields has changed is tried in a new shard. The table `index_shard_pending_stream` and the column `index_shard.recover_pending_streams` are removed.

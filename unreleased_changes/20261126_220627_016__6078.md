* Feature **#6078** : Documents an indexing task wrote are now purged from the index when the task is run again or aborted, or was deleted unfinished, before the stream is indexed again. A task whose documents were lost before they were committed, e.g. as its node died, is put back to be run again by the job `Index Shard Stream Recovery`, which also completes tasks that were missed, purges shards that nobody has open, and warns of tasks that have been `Committing` or streams that have waited to be purged for over an hour.

# Accessibility work list

Every accessibility issue we know of in Stroom's GWT UI, in one place, grouped into batches of
similar work. It gathers:

* the open GitHub issues (the February 2026 audit, #5397, and two older issues);
* the accessibility entries in [`ISSUES.md`](ISSUES.md), which has the detail for each;
* the rules each story is allowed to break in the workbench's
  [`a11y-baseline.json`](stroom-gwt-workbench/test-runner/a11y-baseline.json) (93 stories, as of
  22 October 2026);
* work already agreed but deferred.

Status:

* **Open** - still to do.
* **Check** - the code suggests it has been done since it was reported; confirm (with a story or a
  screen reader) and close or update the issue.
* **Deferred** - agreed to wait for other work.
* **Done** - confirmed, with the evidence.

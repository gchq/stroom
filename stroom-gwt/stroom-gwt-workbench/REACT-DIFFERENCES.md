# Differences between the GWT stories and their React originals

Where a GWT story can't do or check exactly what its React original does, the story asserts what
GWT does and has a `// Differs from React:` comment at that point (see [PORTING.md](PORTING.md)).
Each difference is also listed here, so they can be reviewed together, e.g. to decide whether to
fix the GWT widget, change the React port, or accept the difference.

Kinds:

* **GWT bug** - the GWT widget is wrong, or lacks something it should have (e.g. accessibility).
* **React-only feature** - the React port has an option or behaviour that Stroom's GWT widget
  doesn't have.
* **intentional** - the two are built differently on purpose (e.g. a native element in place of a
  hand-built one), or the GWT story stands in for a React prop with Stroom's own pattern.
* **visual** - they look different but behave the same.

Story ids are the React ones (`<title>--<export name>`), shortened by dropping `widgets-`.
